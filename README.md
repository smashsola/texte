# 🐍 Snake Game

Um jogo simples de Snake feito com HTML, CSS e JavaScript.

## Como jogar

Abra o arquivo `index.html` no navegador e clique em **COMEÇAR**.

Use as setas do teclado ou `W A S D`.

## Estrutura

- `index.html` → estrutura da página
- `style.css` → aparência
- `game.js` → funcionamento do jogo

## Desafio

Depois de clonar o projeto, tente fazer uma alteração e enviar para o GitHub!

Algumas ideias:

- mudar o título;
- mudar as cores;
- aumentar a velocidade;
- adicionar uma mensagem quando bater o recorde;
- criar um botão de pausa.
